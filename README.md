## Часть 1. Модульное тестирование (Unit Tests)

В рамках этого этапа было проведено комплексное юнит-тестирование внутренней логики калькулятора заказов космической бургерной `Stellar Burgers`. Основная цель — обеспечить изоляцию логики и 100% тестовое покрытие.

### Реализованный функционал:
* **Покрытие класса Burger:** Полностью протестированы методы управления составом бургера (`setBuns`, `addIngredient`, `removeIngredient`, `moveIngredient`), а также методы получения цены (`getPrice`) и состава чека (`getReceipt`).
* **Изоляция зависимостей (Mocking):** С помощью фреймворка **Mockito** были внедрены моки и заглушки для связанных сущностей `Bun` (булочки) и `Ingredient` (ингредиенты), что позволило протестировать класс `Burger` в полной изоляции от их реализации.
* **Параметризация:** Для оптимизации кода и тестирования различных комбинаций цен и типов ингредиентов при расчете стоимости (`getPrice`), а также при получении состава чека (`getReceipt`) были применены параметризованные тесты JUnit 4.
* **Контроль покрытия (JaCoCo):** Настроен плагин JaCoCo в Maven. По итогам запуска тестов достигнут показатель **100% покрытия (Code Coverage)** класса Burger.

### Запуск тестов и генерация отчета JaCoCo:
Для запуска юнит-тестов и генерации отчета о покрытии выполните в терминале команду:
```
mvn verify
```
 *После выполнения команда создаст html-отчёт в папке `target/site/jacoco/index.html`.*
